پرتال اعضا و اپ موبایل

Web App اعضا

حساب کاربری عضو باید از «کاربران» ساخته و به پرونده عضو پیوند داده شود. سپس عضو از نشانی زیر وارد می‌شود:

{{ request.scheme }}://{{ request.get_host }}/mobile/

در Chrome موبایل، «نصب Web App» یا منوی مرورگر ← «افزودن به صفحه اصلی» را بزن. برای نصب روی گوشی، سایت باید با HTTPS در دسترس باشد. داده‌های شخصی در حالت آفلاین ذخیره نمی‌شوند.

بازکردن پرتال موبایل

API اتصال به اپ‌های دیگر

خلاصه باشگاه: {{ api_root }}summary/

فهرست محدود اعضا: {{ api_root }}members/

برای ساخت کلید محرمانه، از دستور create_api_key در README استفاده کن. کلید کامل فقط یک‌بار نمایش داده می‌شود؛ آن را داخل برنامه یا Git قرار نده.

Authorization: Bearer <prefix>.<secret>

دسترسی‌های قابل صدور: summary:read و members:read. داده‌ها فقط از باشگاه وابسته به همان کلید خوانده می‌شوند.
